DORTYMISA – WEBOVÉ SOUBORY

V repozitáři GitHub otevři „Add file“ → „Upload files“ a nahraj tyto tři soubory:
- index.html
- styles.css
- script.js

Potom klikni na zelené „Commit changes“.

Poznámka: Toto je statická úvodní verze webu. Fotka v pozadí se načítá z Unsplash. Skutečná administrace pro ukládání změn obsahu není v této verzi zapojená; tu je potřeba přidat samostatně.
